# Pixi.js 固有プロパティ

| プロパティ名    | デフォルト値 | 設定可能な値                               | 説明                 |
| :-------------- | :----------- | :----------------------------------------- | :------------------- |
| `tint`          | `0xFFFFFF`   | 色指定 (乗算色)                            | ティントカラー       |
| `interactive` | `false`      | 真偽値                                     | イベントを受け取るか |
| `cursor`        | `'default'`  | CSSカーソル文字列 (例: `'pointer'`, `'text'`) | マウスカーソル       |
