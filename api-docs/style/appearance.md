# 外観

| プロパティ名        | デフォルト値 | 設定可能な値                                       | 説明             |
| :------------------ | :----------- | :------------------------------------------------- | :--------------- |
| `backgroundColor` | -            | 色指定 (例: `'#ffffff'`, `'red'`, `0xff0000`) | 背景色           |
| `backgroundImage` | -            | 画像URL文字列 (例: `'path/to/image.png'`)        | 背景画像         |
| `borderRadius`    | `0`          | 数値 (全角), 配列 (各角)                           | 角丸半径         |
| `borderWidth`     | `0`          | 数値 (全周), 配列 (各辺)                           | ボーダー幅       |
| `borderColor`     | -            | 色指定                                             | ボーダー色       |
| `opacity`         | `1`          | `0` から `1` の数値                              | 不透明度 (alpha) |
| `visible`         | `true`       | 真偽値                                             | 表示/非表示      |
