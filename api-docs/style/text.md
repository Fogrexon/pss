# テキスト

| プロパティ名      | デフォルト値 | 設定可能な値                                       | 説明             |
| :---------------- | :----------- | :------------------------------------------------- | :--------------- |
| `color`           | `'black'`    | 色指定                                             | 文字色           |
| `fontSize`        | -            | 数値 (ピクセル)                                    | フォントサイズ   |
| `fontFamily`      | -            | 文字列 (フォント名)                                | フォントファミリー |
| `fontWeight`      | `'normal'`   | `'normal'`, `'bold'` など (フォントに依存)         | フォントの太さ   |
| `fontStyle`       | `'normal'`   | `'normal'`, `'italic'`                             | フォントスタイル |
| `textAlign`       | `'left'`     | `'left'`, `'center'`, `'right'`                    | テキスト揃え     |
| `lineHeight`      | -            | 数値 (ピクセル)                                    | 行の高さ         |
| `letterSpacing`   | `0`          | 数値 (ピクセル)                                    | 文字間隔         |
| `wordWrap`        | `false`      | 真偽値                                             | 単語の折り返し   |
| `wordWrapWidth`   | -            | 数値 (ピクセル)                                    | 折り返し幅       |
