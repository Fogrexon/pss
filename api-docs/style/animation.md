# アニメーション

| プロパティ名         | デフォルト値 | 設定可能な値                                                     | 説明                 |
| :------------------- | :----------- | :--------------------------------------------------------------- | :------------------- |
| `animationName`      | -            | 文字列 (例: `'fadeIn'`, `'slideUp'`) (別途定義・実装が必要) | アニメーション名     |
| `animationDuration`  | `0`          | 数値 (秒)                                                        | アニメーション時間   |
| `animationDelay`     | `0`          | 数値 (秒)                                                        | アニメーション遅延時間 |
